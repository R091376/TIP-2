Interaction map

How the two old layers map onto one model.

→ Old chart dock Chart becomes header segment Chart (default on Charts tab)
→ Old chart dock Alerts becomes header segment Alerts (badge count)
→ Old chart dock Symbols becomes header segment Symbols (quick pick)
→ Old bottom Watchlist stays bottom tab (full list / manage)
→ Old bottom Dashboard moves to More (and drawer)
→ Account only in drawer footer (already done)
→ Desktop sidebar unchanged in this proposal (mobile-only)
